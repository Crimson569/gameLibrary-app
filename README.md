НАЗВАНИЕ: GameLibrary
Тема: Каталог игр — платформы и статусы прохождения
Автор: Тварковский Николай
Сценарий: «Каталог игр» помогает пользователю вести список игр и отслеживать платформы, на которых они доступны, а также статус прохождения. Пользователь добавляет игру, указывает платформу и меняет статус, например «Не начата», «В процессе» или «Пройдена».
Стек: React, Typescript
Версия NodeJS: v24.11.1
Готово: Главный экран с базовой информацией о проекте

## Запуск
Из корня скачанного проекта:
```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки
Остановите dev через Ctrl+C. Выполните в frontend:
```bash
npm run build
npm run preview
```

## Адреса страниц

| Адрес | Страница | Описание |
|-------|----------|----------|
| `/` | — | Перенаправляет на `/games` |
| `/games` | Список игр | Каталог игр с платформами и статусами прохождения |
| `/games/new` | Добавление игры | Форма добавления новой игры |
| `/games/:id` | Карточка игры | Подробная информация об игре, где `:id` — идентификатор игры (например, `/games/1`) |
| `/*` | Страница не найдена | Отображается для любого несуществующего адреса |

## Демонстрационные данные

Все записи в каталоге (игры, платформы и статусы прохождения) являются **демонстрационными**: они созданы для показа возможностей приложения и не относятся к реальным данным пользователя.
